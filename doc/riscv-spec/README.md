# Local RISC-V ISA reference sources

This is a search-oriented copy of the AsciiDoc sources from the
[RISC-V ISA Manual repository](https://github.com/riscv/riscv-isa-manual),
published by RISC-V International. The upstream repository identifies the manual
as licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The AsciiDoc chapters, text diagram definitions, examples, and bibliography are
retained for local search. SVG/PNG image assets and Asciidoctor rendering
support files have been omitted, so this is not a buildable copy of the manual.
This directory's imported upstream revision was not recorded; consult each
volume's preface for its stated ratification/version information and do not
assume this snapshot is the latest official specification.
