A git commit must follow the next format:

```text
New | Fix | Change: This is the title

This is the body of the comment.
```

A commit can be:
- New: A new feature, script, flow, tool added to the repo
- Fix: A bug fix
- Change: Any change which is not a fix or a new commit

The body commit must not span over bigger than 100 chars.
Split the long lines to make it readable
